ഇൻസ്ക്രിപ്റ്റ് കീബോർഡ് സഹായി (InScript Typing Guide)

ഇൻസ്ക്രിപ്റ്റ് (InScript) ഭാരത സർക്കാർ അംഗീകരിച്ച ഔദ്യോഗിക മലയാളം ടൈപ്പിംഗ് രീതിയാണ്. ഇതിന്റെ അടിസ്ഥാന നിയമങ്ങൾ താഴെ നൽകുന്നു:

1. സ്വരങ്ങളും സ്വരചിഹ്നങ്ങളും (Vowels & Matras)

ഇടതു കൈയിലെ കീകൾ സാധാരണയായി സ്വരചിഹ്നങ്ങൾക്കും (Matras), Shift അമർത്തുമ്പോൾ സ്വതന്ത്ര സ്വരങ്ങൾക്കുമായി (അ, ആ, ഇ...) ക്രമീകരിച്ചിരിക്കുന്നു.

2. ചില്ലക്ഷരങ്ങൾ ടൈപ്പ് ചെയ്യുന്ന വിധം (Chillu Characters)

അക്ഷരം + ചന്ദ്രക്കല (d) + ZWJ (]) അല്ലെങ്കിൽ മുകളിലെ "ചില്ലുകൾ" ടാബിലെ നേരിട്ടുള്ള ബട്ടണുകൾ ഉപയോഗിക്കുക:

  • ർ = ര (j) + ് (d) + ZWJ (])
  • ൽ = ല (n) + ് (d) + ZWJ (])
  • ൾ = ള (Shift+N) + ് (d) + ZWJ (])
  • ൻ = ന (v) + ് (d) + ZWJ (])
  • ൺ = ണ (Shift+C) + ് (d) + ZWJ (])

3. കൂട്ടക്ഷരങ്ങൾ (Conjuncts)

രണ്ട് വ്യഞ്ജനങ്ങൾക്കിടയിൽ ചന്ദ്രക്കല (d) ടൈപ്പ് ചെയ്താൽ കൂട്ടക്ഷരമായി മാറും:

  • ക (k) + ് (d) + ഷ (Shift+,) = ക്ഷ
  • ത (l) + ് (d) + ര (j) = ത്ര
  • ജ (p) + ് (d) + ഞ (Shift+]) = ജ്ഞ
